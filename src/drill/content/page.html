How fast is it?

      
Some code takes about the same time however much data you give it. Some slows down a little as data grows, and some slows down enormously. Drag the slider to give it more data. Times assume Python does about 10 million simple steps a second.

      

      

      
The trick for working it out: count how many times the innermost line can run. One loop over the list grows with the list. A loop inside a loop checks every pair, which is what gets slow.
