# The use case card

Shaped like the AI Canvas (Agrawal, Gans and Goldfarb): AI as cheap prediction inside a decision.

| Field | Question |
|---|---|
| user | Who uses it? |
| task | The task it helps with |
| decision | What the AI predicts or drafts, from what input |
| action | What happens next, and who does it |
| today | How it is done today, and the cost |
| success | Success, as a number |
| wrong_answer | What a wrong answer costs, and who catches it |
| data | The data to test on |
| feedback | How real outcomes flow back to improve it |
| owner | The owner who decides |
