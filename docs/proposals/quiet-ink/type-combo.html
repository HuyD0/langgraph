Renaming without destroying

LearnCheckBuildExplain

Terraform knows each resource by its address, like databricks_cluster.etl. Rename it, and the plan sees one address gone and a new one: destroy, then create.

A moved block says it's the same thing with a new name.

moved {
  from = databricks_cluster.etl
  to   = databricks_cluster.sales_etl
}
